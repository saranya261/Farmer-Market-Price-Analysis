# Farmer-Market-Price-Analysis

## About the Project
This project analyzes daily mandi price data of tomatoes sourced from Agmarknet.gov.in, India's government agricultural market portal. The goal is to identify seasonal price trends and help farmers make better selling decisions.

## Key Finding
Tomato prices nearly tripled from Rs.1623 in January to Rs.4441 in June 2024 in Andhra Pradesh markets.

## Dataset
- Source: Agmarknet.gov.in
- State: Andhra Pradesh
- Months: January to June 2024
- Markets: Kalikiri, Madanapalli, Palamaner, Pattikonda, Punganur, Vayalapadu

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Files
- `tomato_combined_2024.csv` — cleaned dataset
- `mandi_analysis.ipynb` — analysis notebook
